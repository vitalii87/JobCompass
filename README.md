# JobCompass

JobCompass — локальна GUI-програма для пошуку, пояснюваного оцінювання та
відстеження вакансій. Поточна версія є прототипом на Python 3.11+ і
використовує стандартну бібліотеку та один локальний PDF-парсер `pypdf`.

## Що вже працює

- єдині моделі профілю кандидата, вакансії та заявки;
- графічний інтерфейс на `Tkinter/ttk` для Windows;
- локальне завантаження профілю або резюме у форматі JSON, TXT, DOCX чи PDF;
- пояснюваний match score від 0 до 100%;
- консервативне визначення точних дублікатів;
- інтернет-пошук через Bundesagentur für Arbeit, Arbeitnow і Remotive;
- допоміжний імпорт нормалізованих вакансій із локального JSON;
- атомарне локальне JSON-сховище;
- статуси `Found`, `Interesting`, `Draft`, `Applied`, `Rejected`, `Interview`,
  `Offer` та `Archived`;
- фільтри за джерелом, ключовими словами, локацією, remote та score;
- локальна чернетка супровідного листа й безпечний промпт для зовнішнього AI;
- повна історія статусів і попередження про можливу повторну подачу;
- додатковий CLI для імпорту, перегляду, оцінювання та зміни статусів.

## Запуск

Для підтримки PDF один раз встановіть мінімальну залежність:

```powershell
python -m pip install -r requirements.txt
```

Якщо команда `python` недоступна, використайте `py -3` замість неї.

З кореня репозиторію запустіть GUI:

```powershell
python -m app
```

Або явно:

```powershell
python -m app gui
python -m app gui --data C:\path\jobcompass.json
```

Якщо у Windows доступний лише Python Launcher:

```powershell
py -3.11 -m app
```

Також можна двічі натиснути `run_jobcompass.bat`. Для швидкої перевірки GUI:

1. На вкладці `Профіль` завантажте резюме.
2. На вкладці `Пошук` введіть бажані посади й локації.
3. Виберіть інтернет-джерела та натисніть `Знайти вакансії в інтернеті`.

Пошук виконується у фоновому потоці, тому GUI не зависає. Отримані вакансії
нормалізуються, збагачуються вимогами з німецького опису, дедуплікуються та
зберігаються локально. Кожен новий пошук очищає попередню таблицю й показує
лише поточну видачу; лічильник над таблицею показує її розмір. Історія заявок
при цьому зберігається. JSON-імпорт доступний у `Налаштуваннях` лише як
допоміжний режим.

Формат пошукових фільтрів:

- текстові поля підтримують `Ctrl+C`, `Ctrl+V`, `Ctrl+X`, `Ctrl+A` незалежно
  від активної розкладки клавіатури; правою кнопкою відкривається контекстне меню;
- бажані посади вводяться через кому та працюють як альтернативи
  (`Office Manager, Projektkoordination` означає `Office Manager OR Projektkoordination`);
- додаткові ключові слова необов’язкові; якщо їх кілька, мають збігтися всі
  (`MS Office, SAP` означає `MS Office AND SAP`);
- поле локацій є обов’язковим; кілька міст вводяться через кому та працюють як
  альтернативи;
- радіус від 0 до 200 км обирається окремим повзунком і застосовується до всіх
  введених локацій; Bundesagentur отримує його як параметр пошуку;
- у поточному локальному JSON-пошуку локація порівнюється за назвою міста,
  оскільки імпортовані вакансії не містять географічних координат;
- якщо `Тільки remote` вимкнено, включаються `remote`, `hybrid`, `office` та
  вакансії, формат яких не вказаний.

Після вибору вакансії кнопка `Підготувати / подати заявку` пропонує:

1. створити локальну чернетку супровідного листа для вибраної вакансії;
2. сформувати AI-промпт із профілем, описом вакансії, збігами та ризиками;
3. продовжити без супровідного листа.

Чернетка й промпт не використовують дані інших вакансій і не вигадують факти
про кандидата. Статус `Applied` встановлюється лише після ручного підтвердження,
що заявка фактично відправлена.

Кнопка `Відкрити вакансію` і подвійний клік по результату відкривають оригінальну
сторінку вакансії в браузері. Відправлення залишається ручним.

## Розуміння німецьких вакансій

Під час JSON-імпорту JobCompass локально аналізує сирий німецький опис, якщо
структуровані вимоги відсутні або неповні. Parser розпізнає секції на кшталт
`Ihr Profil`, `Anforderungen`, `Das bringen Sie mit`, `Wünschenswert` і
`Wir bieten`, а також маркери:

- `erforderlich`, `Voraussetzung`, `fundierte Kenntnisse` — обов'язкове;
- `wünschenswert`, `von Vorteil`, `idealerweise` — бажане;
- `keine Voraussetzung`, `nicht erforderlich` — не вимога.

DE/EN таксономія нормалізує поширені професії, навички та мови, наприклад
`Softwareentwickler ↔ Software Developer`, `Python-Entwicklung ↔ Python` і
`Deutsch ↔ German`. GUI показує цитати з опису, на яких ґрунтується extraction.

Для німецькомовної вакансії локальна чернетка та AI-промпт автоматично
створюються німецькою. Мову можна вручну змінити на `Deutsch` або `English` у
вікні супровідного листа. Жодного AI API програма не викликає.

GUI має п'ять вкладок:

1. `Профіль` — завантаження резюме, перевірка й збереження даних.
2. `Пошук` — інтернет-пошук, вибір джерел і фільтрів.
3. `Результати` — match score, ключові збіги, ризики й дії.
4. `Мої заявки` — поточні статуси та повна історія змін.
5. `Налаштування` — шлях до локального сховища й стан інтеграцій.

Командний інтерфейс залишається доступним:

```powershell
python -m app --help
python -m app init
python -m app import-jobs path\to\jobs.json
python -m app list-jobs
python -m app match path\to\profile.json
python -m app set-status source:id Interesting
python -m app list-applications
```

За замовчуванням локальні дані зберігаються в `data/jobcompass.json` і не
потрапляють до Git. Інший шлях можна передати перед командою:

```powershell
python -m app --data C:\path\jobcompass.json list-jobs
```

## Завантаження резюме

- `JSON` завантажується як готовий структурований профіль.
- `TXT` обробляється локально за підписаними секціями на кшталт `Skills:` або
  `Навички:`.
- `DOCX` читається локально стандартними засобами Python.
- `PDF` читається локально через `pypdf`; файли нікуди не надсилаються.
- PDF-скани без текстового шару поки потребують попереднього OCR.

Після завантаження резюме витягнутий профіль одразу зберігається локально та
може використовуватися для пошуку. Ім’я, email, бажані професії та всі інші
ручні поля необов’язкові. Якщо вони порожні, оцінювання спирається лише на
факти, які вдалося знайти у резюме; тому автоматично витягнуті дані бажано
перевірити в GUI. Програма не вигадує відсутні дані.

## Формат профілю JSON

```json
{
  "full_name": "Candidate Name",
  "email": "candidate@example.test",
  "phone": "+49 000 000000",
  "summary": "Backend developer focused on reliable local software.",
  "desired_roles": ["Python Developer"],
  "skills": ["Python", "SQL", "Git"],
  "languages": ["English", "Ukrainian"],
  "years_experience": 3,
  "preferred_locations": ["Berlin"],
  "remote_only": false
}
```

## Мінімальний формат вакансій

Файл може містити список вакансій або об'єкт із полем `jobs`. Поля `source`,
`external_id`, `title` і `company` є обов'язковими.

```json
{
  "jobs": [
    {
      "source": "example",
      "external_id": "123",
      "title": "Python Developer",
      "company": "Example GmbH",
      "location": "Berlin",
      "url": "https://example.test/jobs/123",
      "required_skills": ["Python", "SQL"],
      "preferred_skills": ["Docker"],
      "required_languages": ["English"],
      "minimum_years_experience": 2,
      "remote": true,
      "work_mode": "remote",
      "employment_type": "full-time",
      "published_at": "2026-08-01T09:00:00+00:00"
    }
  ]
}
```

## Конфіденційність і межі прототипу

Профіль, вакансії та історія заявок залишаються у локальному файлі
`data/jobcompass.json`. JobCompass не викликає AI API: кнопка AI-промпту лише
готує текст, який користувач може перевірити та скопіювати.

У поточній версії немає OCR для PDF-сканів, REST API, embeddings, Ollama,
прямого scraping LinkedIn/Indeed/StepStone або автоматичної подачі заявок. Кнопка відкриття
вакансії передає керування браузеру, а успішну подачу підтверджує користувач.
Поточне онлайн-покриття забезпечують публічні джерела Bundesagentur für Arbeit,
Arbeitnow і Remotive. Нові конектори можна додавати без зміни моделей, matcher
і сховища.

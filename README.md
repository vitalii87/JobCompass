# JobCompass

JobCompass — заготовка Python-застосунку для подальшої реалізації логіки роботи з вакансіями.

## Структура

- `app/core` — основні моделі та механізми зіставлення.
- `app/sources` — джерела даних.
- `app/storage` — шар зберігання даних.
- `app/interfaces` — зовнішні інтерфейси застосунку.
- `tests` — автоматизовані тести.

Бізнес-логіка та зовнішні залежності поки не додані.
